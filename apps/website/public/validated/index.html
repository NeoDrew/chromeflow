What "validated" actually means

We run a documented procedure on each platform against the live site. The status reflects the result of that run: Working means every step of the procedure succeeded; Partial means the typing or read path works; Not working would mean a known regression. All procedures live in tests/antibot/ and the JSON powering this page is regenerated by tests/antibot/run-local.sh on every release.
